# Decentralized tree traffic

**Disclosure status:** `SCOPE-GATED`. No verdict or supported procedure exists.

**Traffic pattern:** Workers would delegate or route work through a tree without relying solely on the current coordinator-to-worker adapter path.

**Historical evidence:** The topology findings explicitly state that decentralized trees have no verdict and worker-side MCP/delegation permissions were outside scope. See [topology findings](../../../../docs/topology-investigation-findings.md) and [scope issue #42](https://github.com/tbrandenburg/opencode-a2a-lite/issues/42).

## Adapter lens

Do not infer worker-side delegation support from coordinator-to-worker interoperability. Before any topology test, first obtain a scope decision describing which existing adapter contract is being exercised without adding worker-side tools, roles, or platform features.

None. Do not add execution steps until issue #42 resolves scope and the adapter boundary is specified.
